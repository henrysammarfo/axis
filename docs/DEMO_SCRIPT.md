## Full script (~2:00)

### 0:00 – 0:15 · Landing → Google

**On screen:** https://axis-mainnet.vercel.app → click through to onboard / Continue with Google.

**Say:**  
“This is what DeFi looks like for normal people. Continue with Google — one button. No MetaMask. No seed phrase.”

### 0:15 – 0:30 · Judge proof

**On screen:** Open `/proof` (Settings → Judge proof, or navigate directly).

**Say:**  
“Same Google account, same address — upgraded in place with EIP-7702. Here’s the Type-4 transaction hash, and here’s the ZeroDev Smart Routing Address for deposits from any chain.”

*(Point at green checks: UA, 7702, SRA.)*

### 0:30 – 0:50 · Strategy

**On screen:** Dashboard — pick **Moderate** + **Maximize yield**, set budget to what you deposited (e.g. $50).

**Say:**  
“I set how much AXIS can use, and how aggressive I want to be. The strategy is a real allocation matrix — not AI guessing.”

### 0:50 – 1:10 · Deposit

**On screen:** Show SRA / deposit address — paste or show a prior deposit arriving. If already funded, show wallet USDC balance on the Smart route card.

**Say:**  
“I send USDC to one deposit address — even from another chain. ZeroDev routes it. Arbitrum is the settlement layer. I never bridge myself.”

### 1:10 – 1:35 · Begin / Apply (zero signing)

**On screen:** Tap **Begin — put $X to work** *or* **Apply best route**. Wait for success toast / positions. **No wallet popup.**

**Say:**  
“One tap. No signing. AXIS puts my money to work with a policy-bounded session key — gas sponsored. After Google login, I never approve a transaction again.”

### 1:35 – 1:50 · Proof of work

**On screen:** Positions / Vaults + Agent Log. Click an Arbiscan link if visible. Optional: Smart route “What AXIS did.”

**Say:**  
“Real positions. Real Arbiscan transactions. AXIS explains what it did in plain English.”

### 1:50 – 2:00 · Close

**On screen:** Landing or dashboard hero; optional 390px mobile width.

**Say:**  
“AXIS — powered by Arbitrum, Universal Accounts, Magic, and ZeroDev. Set it. Forget it. Earn.”
